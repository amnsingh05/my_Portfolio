# Aman Singh — Personal Portfolio

A modern, responsive personal portfolio website designed and developed to showcase my work, skills, AI/ML projects, experience, and contact information.

The portfolio focuses on a clean editorial-style interface with interactive elements, smooth animations, responsive layouts, and project case-study interactions.
